MT4 - Cửa hàng (Artistic style)
===============================

This project is a ready-to-run React + Vite + Tailwind scaffold for the "Cửa hàng" section.
Style: Artistic (golden/brown accents).

How to run:
1. Install Node.js (LTS)
2. cd <project-folder>
3. npm install
4. npm run dev
5. Open http://localhost:5173

Notes:
- This scaffold includes a demo "payment" form that is non-functional (simulated locally).
- Replace mock data, connect real payment gateway, and add backend as needed.
